# Mohammad Aquib Siddiquee — Portfolio

This is a plain HTML/CSS/JavaScript portfolio for GitHub Pages.

## Publish on GitHub Pages

- Repository: `aquibsid/CV`
- Branch: `main`
- Folder: `/ (root)`
- Expected URL: `https://aquibsid.github.io/CV/`

## Files

- `index.html` — portfolio content
- `style.css` — design and responsive layout
- `script.js` — mobile navigation, skills and language switch
- `assets/icons/favicon.svg` — favicon
- `Mohammad-Aquib-Siddiquee-CV.pdf` — upload your CV PDF to the repository root

No npm, build command, framework or server is required.

## Important

The CV download buttons will work after `Mohammad-Aquib-Siddiquee-CV.pdf` is uploaded beside `index.html`.
